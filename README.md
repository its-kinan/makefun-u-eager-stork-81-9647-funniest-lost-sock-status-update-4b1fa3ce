Entrants write one status update of 120 characters at most in the voice of a lost sock. An AI judge reads them two at a time and the funniest line takes the whole reward.

The program writes a single 100-character status update from a lost sock to `/output/entry.txt`:

> I'm not lost. I'm under the sofa, married to a dust bunny, raising lint. My pair moved on in a week.

## Run it

```sh
node main.ts
```
